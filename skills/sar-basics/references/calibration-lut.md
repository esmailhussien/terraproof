# Sentinel-1 Level-1 calibration LUTs in practice

Reference for [SAR basics](../SKILL.md). Use a maintained processor (ESA SNAP,
GDAL ≥ 3.4 `SENTINEL1_CALIB` subdatasets, or a provider's analysis-ready backscatter)
when available; this page documents what those tools do so their output can be
checked.

## What the product provides

Each Level-1 product has, per measurement (swath × polarisation), a calibration
annotation file in `annotation/calibration/` with four LUTs [S1]:

| LUT | XPath in the calibration XML | Converts to |
|---|---|---|
| `Aβ` | `/calibration/calibrationVectorList/calibrationVector/betaNought` | β⁰ (normalised in slant range) |
| `Aσ` | `/calibration/calibrationVectorList/calibrationVector/sigmaNought` | σ⁰ (normalised in the ground-range plane) |
| `Aγ` | `/calibration/calibrationVectorList/calibrationVector/gamma` | γ⁰ (normalised in the plane perpendicular to slant range) |
| `Adn` | `/calibration/calibrationVectorList/calibrationVector/dn` | reverts the final product scaling |

Each `calibrationVector` has a `line`, an `azimuthTime`, a space-separated `pixel`
list and the LUT values at those pixels. LUTs are sub-sampled in range and updated
in azimuth; values for pixels between LUT points are found by **bilinear
interpolation**, using the vectors nearest in azimuth [S1, S2].

Distributed-target calibration, with `DN` the GRD pixel amplitude or, for SLC,
`sqrt(I² + Q²)` [S1]:

```text
σ⁰ = DN² / Aσ²      β⁰ = DN² / Aβ²      γ⁰ = DN² / Aγ²      (linear power)
σ⁰_dB = 10 * log10(σ⁰)
```

Thermal noise: a noise LUT (linear power) is provided per measurement; it must be
scaled by the same calibration LUT as the image and is removed by subtraction [S2].
Algebraically this is `(DN² − η) / A²` with `η` the interpolated noise LUT value.
Subtraction can give zero or negative power in very dark areas; decide and record
how such pixels are handled before taking a logarithm.

## Window-wise σ⁰ from a GRD measurement (tested sketch)

```python
import numpy as np
import xml.etree.ElementTree as ET

def lut_window(calibration_xml, rows, cols, name="sigmaNought"):
    """Bilinear LUT values for 1-D arrays of image rows and columns."""
    root = ET.parse(calibration_xml).getroot()          # <calibration>
    vectors = root.findall("calibrationVectorList/calibrationVector")
    lines = np.array([int(v.findtext("line")) for v in vectors])
    along_range = np.vstack([
        np.interp(cols,
                  np.array(v.findtext("pixel").split(), dtype=float),
                  np.array(v.findtext(name).split(), dtype=float))
        for v in vectors
    ])                                                   # (n_vectors, len(cols))
    idx = np.clip(np.searchsorted(lines, rows), 1, len(lines) - 1)
    l0, l1 = lines[idx - 1], lines[idx]
    t = np.clip((rows - l0) / (l1 - l0), 0.0, 1.0)[:, None]
    return (1 - t) * along_range[idx - 1] + t * along_range[idx]

def sigma0_window(dn, calibration_xml, row_off, col_off):
    rows = np.arange(row_off, row_off + dn.shape[0])
    cols = np.arange(col_off, col_off + dn.shape[1])
    a = lut_window(calibration_xml, rows, cols)
    power = dn.astype("float64") ** 2 / a ** 2
    return np.where(dn == 0, np.nan, power)             # 0 = no-data border here
```

Read `dn` with a rasterio window from the measurement GeoTIFF
(`src.read(1, window=Window(col_off, row_off, width, height))`). Treating DN 0 as
no-data is a processing choice for the black-fill border described for Level-1
products [S2]; document it.

Check the implementation against ESA's numerical example: average intensity
`<DN²> = 22142.71` with `Aσ = 319.946` gives `σ⁰_dB = −6.65 dB` [S1]. Average
`DN²` (intensity), not `DN`, before calibrating an area [S1].

## Relations between β⁰, σ⁰ and γ⁰

The calibration annotation uses an ellipsoid (inflated by an average height) as
Earth model, so with `α` the incidence angle on that model the LUTs differ only by
the area-normalisation factor `sin α` (σ⁰) or `tan α` (γ⁰) [S1]:

```text
σ⁰ = β⁰ * sin α      γ⁰ = β⁰ * tan α      γ⁰ = σ⁰ / cos α      cos α = Aγ² / Aσ²
```

(The first two follow from the LUT definitions; the last is given in [S1].) This
ellipsoid γ⁰ is **not** terrain-flattened γ⁰: radiometric terrain correction
replaces the ellipsoid normalisation area with a DEM-derived illuminated area
[S3, S4].
